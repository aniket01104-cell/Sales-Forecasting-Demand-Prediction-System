# Sales Forecasting & Demand Prediction System

## Project Overview

This project is an end-to-end Sales Forecasting and Demand Prediction System built using:

- Python
- Machine Learning
- Tableau Dashboard
- SQL Analysis
- Gradio Deployment

The system analyzes historical sales data, performs feature engineering, builds predictive models, and visualizes business insights through an interactive Tableau dashboard.
